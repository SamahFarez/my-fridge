# Room Fridge (Android app)

Offline meal and fridge app. Everything is stored on your phone only.

## Get the APK
1. Upload everything in this folder to a new GitHub repository (keep the `.github` folder).
2. Open the repository's **Actions** tab. The "Build Room Fridge APK" job starts by itself (about 5 minutes).
3. When it shows a green check, open it and download **room-fridge-apk** at the bottom.
4. Unzip it on your phone and open `app-debug.apk` to install.
